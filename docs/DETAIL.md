# 个人知识库

把本机文件整理成**树状知识库**：上传后能在应用里直接读，AI 可以检索它，也可以针对某一篇文档对话。文件只存在这台电脑上（默认 `~/.dsh/kb`，可配置）。

## 能做什么

- **多知识库 + 树状目录**：左栏「知识库」→ 新建库 / 新建文件夹 / 导入文件。**文件树栏可以收起**：顶部最左边那个箭头按钮收起（阅读区随之变宽），收起后左边留一条细条，点它再展开。**点文件夹 = 选中它并展开/收起**，之后「导入文件」「新建文件夹」都落在这个文件夹里；已有内容可以**直接拖到文件夹上**，或用行上悬停出现的「移动到…」；空文件夹会显示「（空文件夹）」提示，不会让你以为点击没反应。行上还能重命名/删除（键盘 F2 / Delete 也行）。
- **在线查看（原版式）**：点文档直接看原样。**Word / PPT / Excel 会先用本机 LibreOffice 转成 PDF、再逐页渲染成图片，由插件自己的阅读器显示**（不是把浏览器 PDF 阅读器塞进来）。**左侧有可点击的缩略图栏**，点哪页跳哪页、当前页高亮，工具栏最左边那个按钮可以收起/展开；顶部还有**页码输入框 + 上一页/下一页**，默认「连续」滚动（滚到哪页页码跟着变），也可以切「单页」一页一页翻；页面铺满阅读区、按页标号、滚到才加载。PDF 文件仍用浏览器阅读器，图片直接显示。第一次打开要等渲染（大文件几十秒），之后走缓存秒开；导入时也会在后台先转一份。想看更大就点「大屏」——**一页一页铺满整个窗口**（左上角页码、‹ › 翻页、也可以切「连续」），方向键 ← → 也能翻，**右上角「恢复」**（或 Esc）回到面板。桌面端不允许插件页面开新窗口，所以做成了应用内全屏；想存原件点「下载」。
- **文字版随时可切**：Office 文档右上角有「原版式 / 文字」开关。文字版是抽取出来的正文，用来快速读、也用来给 AI 检索。
- **全文检索**：右上角搜索框直接搜正文，中文两字词（如「农药」）也能命中。命中结果带片段与章节，点一下跳到正文那一段并高亮。
- **AI 检索**：模型有三个工具——`kb_list`（有哪些库和目录）、`kb_search`（检索片段）、`kb_read`（按偏移读正文）。任何会话里问「我的知识库里有没有…」都会自动用上。
- **针对文档对话**：文档页点「问 AI」，会在会话输入框里预填一段带文档 id 的提问，你补上问题发送即可；模型会先读文档再回答，并给出处。

## 支持的格式

| 类型 | 原版式预览 | 文字阅读 | 正文索引 |
|---|---|---|---|
| md / txt / csv / json / 代码等文本 | — | ✅ | ✅ |
| html | — | ✅ | ✅ |
| docx / pptx / xlsx | ✅（转 PDF） | ✅ | ✅ |
| doc / ppt / xls（老格式） | ✅（转 PDF） | — | 不支持（会提示） |
| pdf | ✅（浏览器阅读器） | — | ✅ 有文字层的 PDF；扫描件会提示"没有文字层" |
| png / jpg / gif / webp / bmp / svg | ✅ | — | 不索引（图片没有文字） |

## 存放位置与隐私

- 默认目录：`$DSH_HOME/kb`（Windows 上是 `C:\Users\<你>\.dsh\kb`），里面有 `kb.db`（本地 SQLite 全文索引）和 `files/`（原始文件，文件名按 id 重命名）。
- 想换目录：在插件配置里设置 `root`，重启后生效。**已有文件不会自动搬迁**。
- 不上传：除了「向量检索」（默认关闭，需要你自己填 OpenAI 兼容的 embeddings 接口）以外，插件不发任何网络请求。

## 设置

两个入口，内容一样：

- **面板内**：知识库页面右上角的齿轮按钮，直接在页面里看设置，「返回」回文档；
- **系统设置**：左栏最底部的「设置」（快捷键 `Mod+,` / `Mod+Alt+,`）→ 左侧导航里的「知识库」一节。

里面能看存放目录、文档/片段/向量统计，做「重建全部索引」「清理预览缓存」，还能**直接配向量检索**（接口地址 / 模型 / API Key，带「测试连接」）——保存即生效，不用重启；配完点一次「重建全部索引」给已有文档补向量。

## 看板

页面顶部「文档 / 看板」切过去就是看板，一屏看完知识库的规模与使用情况：

- **规模**：知识库数、文档数、检索片段数、总大小、向量数与覆盖率
- **文件类型分布**：每种后缀有多少篇、占多少空间
- **解析状态**：已索引 / 排队 / 解析中 / 失败，各知识库各有多少篇
- **最近 7 天检索**：柱状图 + 总次数、今日次数、零命中率、平均耗时、混合检索次数
- **热门检索词**：按出现次数排序
- **最近检索 / 最近添加**：最近的查询（命中数、模式、耗时）与最近上传的文档

检索记录写在本机 `kb.db` 的 `search_log` 表里，只保留最近 2000 条，不外发、不影响检索速度（写失败也不会影响结果返回）。右上角「刷新」重新拉一次。

## 已知限制

- 老版 Office（`.doc/.ppt/.xls`）能看原版式，但不抽正文，所以搜不到里面的字。
- 扫描版 PDF、纯图片没有文字层，搜不到内容（后续可以考虑接 OCR）。
- 原版式预览依赖本机的 LibreOffice 转换（DSH 自带）：第一次打开大文件要等，最大输入 50 MB。转换出的 PDF 与逐页图片存在库目录里（页数多的文件会占几十 MB），源文件改了会自动重做；设置页有「清理预览缓存」可以随时清掉。
- 超过 200 页的文档只渲染前 200 页（会明确提示），要看完整版就点「下载」用系统里的 Office 打开。
- 向量检索是可选项：开启后每次检索会把查询文本发给你配置的 embeddings 服务；索引时也会把片段发过去。
- 文字版一次最多展示 24000 字，超长文档用「继续加载」翻页。
